# Переключение локального и Yandex RAG

В чате выберите базу рядом с полем сообщения. «Локальная БЗ» использует
прежний граф ассистента. «Yandex RAG» отвечает по облачному публичному индексу
без передачи истории диалога, ролей, личной памяти, вложений или результатов БД.
Публичность текущего вопроса подтверждается отдельно перед каждой отправкой.

По умолчанию оба сервиса используют прежний путь. Значения в `.env`:

```dotenv
ASSISTANT_RAG_BACKEND=local
CONSULTANT_RAG_BACKEND=local
RAG_YANDEX_INDEX_ID=fvtj92hju8ugctot210n
RAG_YANDEX_MODEL=aliceai-llm
```

Вместо `local` можно указать `yandex`. После изменения настроек перезапустите
соответствующий сервис. В API можно выбрать режим отдельно для запроса,
не меняя настройки сервера:

```json
{"message":"Как найти электронный рецепт по СНИЛС?","rag_backend":"yandex","confirmed_public_for_external_cloud":true}
```

Ассистент: `/api/v1/chat`, ключ `X-Internal-Token`.
Консультант: `/api/v1/consultant/chat`, ключ `X-Consultant-Key`.
Для выбора локального пути: `"rag_backend":"local"`.
Если консультант запущен только с `CONSULTANT_RAG_BACKEND=yandex`, локальная модель
не создаётся: для возврата к ней измените настройку на local и перезапустите сервис.

У ассистента и консультанта разные инструкции в `src/viio_rag/prompts.py`:
ассистент даёт объяснения и планы, консультант — краткие процедуры с источниками.
Их можно переопределить отдельно через `RAG_YANDEX_ASSISTANT_PROMPT` и
`RAG_YANDEX_CONSULTANT_PROMPT` в `.env` (кавычки для многострочных значений).
Изменения применяются после пересоздания сервиса rag.

RAG читает свои ключ и каталог из `RAG_YANDEX_API_KEY` / `RAG_YANDEX_FOLDER_ID`;
в Compose они по умолчанию используют уже настроенные `CONSULTANT_YANDEX_*`.
Ключи клиенту и браузеру не передаются.

Перед использованием индекса создайте локальный манифест:
`python RAG/scripts/prepare_managed_runtime.py`. Он связывает загруженные
публичные файлы с точными версиями документов VIIO. Папка `RAG/state`
подключается к сервису только для чтения. До запроса и перед выдачей ответа
сервис проверяет публичный доступ, активность и SHA-256 всего корпуса.
Любое несовпадение блокирует облачный режим до обновления индекса и манифеста.

Текущий индекс тестовый, срок жизни — одни сутки от создания. При истечении
срока облачный запрос вернёт 503; локальная БЗ продолжит работать.
Если модель не выполнила поиск или не сослалась на известные файлы, ответ также
не выдаётся. Автоматического перехода между режимами при ошибке нет.
