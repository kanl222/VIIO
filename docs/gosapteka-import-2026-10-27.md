# Документы ГосАптеки и исправление списка источников

27 октября 2026.

## Загрузка

По запросу пользователя скачаны все **40 файлов раздела документации** со [страницы ИС «Лекарственное обеспечение»](https://gosapteka56.ru/onas/osmp/is-lekarstvennoe-obespechenie.html): 31 PDF, 4 DOCX, 2 RAR и 3 ZIP. Ссылка Яндекс.Диска раскрыта до PDF внутри публичной папки. Учтён `<base href>` сайта; ссылки из навигации не включены в импорт.

Размер оригиналов — **87 227 257 байт**. Они сохранены:

- локально: `D:\Source\VIIO\data\gosapteka56\2026-10-27\originals`;
- в постоянном файловом хранилище VIIO с исходными именами и MIME-типами, включая DOCX и архивы.

Все 40 оригиналов получили `is_public=true` без ограничений по роли или подразделению. Загруженные раньше 30 документов не изменялись. Для двух длинных инструкций дополнительно созданы пять текстовых частей, чтобы публикации не обрезались по лимиту 50 000 символов.

Итог импорта: **45 новых записей каталога** (40 оригиналов + 5 частей), **43 публикации** для внешнего консультанта. Две длинные инструкции доступны ему через части; полный исходный PDF сохранён. Всего в каталоге стало 75 документов. Владелец пакета: `gosapteka56-public-import-2026-10-27`.

Реестр с URL, локальными путями, SHA-256, идентификаторами документов и публикаций: [gosapteka-files-2026-10-27.json](gosapteka-files-2026-10-27.json).

## Извлечение текста и ограничения

- PDF прочитаны через pypdf, DOCX — python-docx. Текст XLS из архива извлечён полностью. Старая инструкция DOC из ZIP обработана antiword.
- Распоряжение №740 — скан на 16 страницах. Все страницы распознаны Tesseract на CPU; первая и последняя страницы просмотрены визуально. Исправлено однозначное распознавание номера на первой странице `F40 → 740`. OCR-текст помечен как автоматический; таблицы не сверялись по каждой ячейке, оригинал имеет приоритет.
- В большом справочнике Excel **205 744 строки и 53 столбца**. Полный оригинал архива сохранён и доступен для скачивания; в БЗ индексируются структура и первые восемь строк, **не весь справочник построчно**.
- Два ZIP содержат установщики. Сохранены архивы и индекс их состава; исполняемые файлы не запускались и не превращались в текстовую справку.
- Импорт проверенного текста бинарного оригинала выполняется доверенным административным скриптом. Обычная пакетная HTTP-загрузка не открыта для неподготовленных DOCX/архивов; её прежние ограничения сохраняются.

## Проверки и поиск

Все **40/40 оригиналов** скачаны через API с ролью сотрудника и сверены по SHA-256. Проверка повторена после перезапуска API: все файлы сохранились без изменения содержимого; 45 импортированных записей общедоступны, 43 публикации доступны внешнему консультанту.

Первый контрольный вопрос о модуле «Управление сотрудниками» выявил проблему ранжирования: длинная общая инструкция вытесняла нужный документ. Добавлен приоритет совпадений в заголовке и ограничено влияние частоты слов в длинном тексте. После обновления нужная инструкция стала первой; внешний консультант ответил по ней.

Получены ответы по опубликованным документам о модуле сотрудников, поиске электронного рецепта по СНИЛС/карте и пакете документов для доступа. Это проверка получения контекста и доступности источников, не полная экспертная оценка каждого утверждения модели.

## Один список источников в чате

Исправлено дублирование из пользовательского скриншота. Интерфейс убирает завершающий список модели, только если все его названия уже присутствуют в структурированных материалах. Остаётся один блок «Предоставленные материалы». Повторные вложения с одинаковым ID также объединяются.

Правка применяется при отображении новых и сохранённых сообщений; текст истории не переписывается. Блоки кода, ссылки на документы внутри объяснения и неизвестные названия сохраняются. Ошибка сначала воспроизведена тестом реального React-компонента: название встречалось дважды вместо одного. После исправления этот тест и четыре дополнительных проверки проходят. Проверена HTML-структура SSR; отдельный браузерный скриншот не снимался.

Коммиты перед обновлениями: `330a732` (источники), `6829771` (полный набор тестов в Docker), `53737c9` (оригиналы и импорт), `122992f` (релевантность поиска). Веб-чат и API обновлены, рабочие сервисы healthy. Локальные оригиналы и извлечённые тексты находятся в исключённой из Git папке `data/`; в репозитории сохранены скрипты, реестр и результаты проверок.
