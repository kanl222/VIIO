# Yandex Cloud: только подтверждённый публичный текст

## Консультант с поиском по материалам

Для полноценного консультанта задайте `CONSULTANT_PROVIDER=yandex`,
`CONSULTANT_ENABLED=true`, ключи доступа консультанта и источника,
`CONSULTANT_YANDEX_API_KEY` и `CONSULTANT_YANDEX_FOLDER_ID`.
Модель выбирается через `CONSULTANT_MODEL` (при пустом значении —
`CONSULTANT_YANDEX_MODEL`). Отдельный YANDEX_ENABLED для этого режима не нужен.

Обычный endpoint `/api/v1/consultant/chat` требует
`confirmed_public_for_external_cloud: true` вместе с message.
Без подтверждения вопрос не передаётся модели. Вызывающий интерфейс должен
получить это подтверждение от пользователя; автоматически подставлять его нельзя.
Существующий веб-интерфейс пока не запрашивает это подтверждение, поэтому
его запросы к консультанту Yandex будут отклоняться до добавления такого согласия.

Материалы допускаются только с явным классом доступа `public` («Публичный»),
который шлюз получает из актуального каталога (`is_public=true`).
Класс означает открытые данные для всех, включая гостей и внешний облачный
консультант. Обычная публикация ограниченного документа не меняет его класс
и не разрешает передачу в облако. При отсутствии класса шлюза материал
не отправляется. `CONSULTANT_CLOUD_PUBLIC_MATERIAL_HASHES` в рабочем пути
больше не используется; задавать эту переменную не нужно.
Доступ к памяти и внутреннему контексту других агентов отсутствует.
После настройки пересоберите и перезапустите consultant.

## Изолированный запрос без поиска

В сервис Consultant добавлен отдельный POST `/api/v1/consultant/yandex/chat`.
Он не использует поиск, документы, историю, память, инструменты агентов или диагностику содержимого.
Обычная публикация документа не даёт разрешения отправлять его в облако.

Настройте в `.env`:

```dotenv
CONSULTANT_YANDEX_ENABLED=true
CONSULTANT_API_KEY=<отдельный ключ доступа VIIO, минимум 32 символа>
CONSULTANT_YANDEX_API_KEY=<API-ключ Yandex Cloud>
CONSULTANT_YANDEX_FOLDER_ID=<каталог Yandex Cloud>
CONSULTANT_YANDEX_MODEL=aliceai-llm
```

Пересоберите и перезапустите сервис consultant. Для этого отдельного endpoint
CONSULTANT_ENABLED включать необязательно. Существующий консультант использует прежнего провайдера.
Модель можно задать именем или полным URI `gpt://...`.

Запрос с заголовком `X-Consultant-Key`:

```json
{"message":"Объясни закон Ома", "confirmed_public_for_external_cloud":true}
```

Вызывающая сторона должна получить явное подтверждение публичности всего текста
для передачи внешнему облаку. Поле обязательно; строки вместо boolean запрещены.
Это подтверждение пользователя, а не автоматическое распознавание конфиденциальных данных.
Интеграция с веб-интерфейсом и выдача документов в облако не включены.
По умолчанию интеграция выключена; ключи в репозиторий не добавляются.

API: https://aistudio.yandex.ru/docs/ru/ai-studio/quickstart
