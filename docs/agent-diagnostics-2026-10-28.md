# Локальная диагностика агентов — 28 октября 2026

По запросу пользователя реализован отдельный сайт на React + TypeScript
для основного агента и консультанта. Он запущен на http://localhost:3010.
Docker публикует порт исключительно на `127.0.0.1:3010`.

## Возможности

Журнал завершённых запросов с фильтрами по вопросу, агенту, результату выполнения
и ручному разбору. Сводка текущей выборки показывает число ошибок, p50/p95
времени и отмеченные причины неверных ответов. Успешный HTTP-запрос не считается
автоматически верным ответом.

В выбранном запросе видны маршрутизация, фактические сообщения и результаты
вызовов модели, поисковые кандидаты после проверки доступа, отобранные фрагменты,
окончательный ответ и проверки актуальности доступа. Консультант отдельно
показывает поиск публикаций и выбор отрывков из них. Тексты кандидатов и отбор
расположены рядом; списки имеют собственную прокрутку.

Есть эталонный ответ, буквальная проверка фразы по этапам, ID нужного документа,
оценка 1–5, ручная отметка этапа ошибки и заметки. Сохранённые ответы на одинаковый
вопрос можно сравнить. Выбранная трасса экспортируется в JSON.

## Изоляция и совместимость

- Каждый агент пишет в отдельный том; сайт читает эти тома без права записи.
  Разборы сохраняются в третьем томе.
- Сайт не получает рабочие ключи и доступ к БД VIIO. Сервер проверяет Host,
  Origin для записи, идентификаторы и размер полей; добавлены CSP и `no-store`.
- Формат ответов чат-API сохранён. Без `VIIO_TRACE_DIR` коллектор отключён.
  Ошибка записи трассы не ломает ответ. Дополнительная диагностическая проверка
  публикаций также не должна ломать успешный поиск.
- Скрытые рассуждения и метаданные модели с ними не записываются. Фиксируются
  видимые сообщения, служебные настройки из явного разрешённого списка и хеш
  системного промпта; ключи и заголовки авторизации не копируются.
- Рабочий промпт консультанта сохранён при сборке из отдельного временного
  контекста. Его SHA-256 до и после запуска:
  `c49dae605460f90a0bcfb58c74a29880d55ff6e66fade5f8024f19490ee6b38b`.
  Параллельные незавершённые изменения `Consultant/src/viio_consultant/prompts.py`
  не включались в работающую сборку и остались в рабочем дереве.
- Чужие изменения и результаты параллельного исследования поиска не изменялись.
  База знаний не переиндексировалась в рамках этой задачи.

## Проверка

1. Полная сборка React с TypeScript прошла в Docker.
2. Полный набор сервисных проверок: **269 passed, 38 skipped**. Запуск из
   отдельного каталога исключил загрузку рабочей `.env`; задан собственный
   временный каталог. Пропущены проверки с отдельной PostgreSQL тестовой БД.
3. **7** тестов локального коллектора и сервера прошли: изоляция параллельных
   запросов, запись ошибок, отказ записи, исключение служебных секретов и скрытых
   метаданных, сохранение разбора, Host/Origin, обход путей и раздача React.
4. **2** точечных теста поиска прошли: недоступные кандидаты не экспортируются,
   диагностическая проверка публикаций не ломает успешный результат. Первый
   также включён в полный набор выше; второй добавлен после него.
5. Реальный вопрос обоим агентам: «Как оформить начальные остатки в Госаптеке?».
   Оба вернули HTTP 200, записи обнаружены на сайте:
   - основной: `bc5c887f20f3420cbe4878e5282f083c`, 8 событий,
     45 разрешённых кандидатов → 5 фрагментов, 2 вызова модели;

     40 кандидатов → 4 публикации → 2 отрывка, 2 вызова модели.
   Эти запросы проверяют запись цепочки, а не правильность ответа по существу.
6. В браузере проверены сохранение заметки и её сохранность после перезагрузки,
   сравнение двух ответов, буквальное отсутствие контрольной фразы на всех
   четырёх этапах. Проверочная заметка оставлена без оценки и диагноза ошибки.

Sentrux: существующее число циклов не изменилось (1 → 1), связность снизилась
с 0,0817 до 0,0786. Общий сигнал 5697 → 5681; отмечена одна дополнительная

## Ограничения

Трассируются новые завершённые запросы. Старую историю и аварийно прерванный
процесс задним числом восстановить нельзя. Коллектор обрезает отдельные текстовые
поля после 100000 символов с видимой пометкой; при превышении 8 МБ заменяет события
сообщением об ограничении. Сроки очистки и инструкции запуска описаны в
`Diagnostics/README.md`. Разборы не отправляются агентам и не меняют их поведение.
