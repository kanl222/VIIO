# Единый агент: Yandex AI Studio

Основной агент отвечает на вопросы, пишет код и вызывает доступные пользователю
инструменты. Отдельные coder и DB-агент в приложении не создаются.

В корневом `.env` задайте:

```dotenv
LLM_PROVIDER=yandex
YANDEX_API_KEY=<API-ключ Yandex AI Studio>
YANDEX_FOLDER_ID=<идентификатор каталога>
YANDEX_MODEL=aliceai-llm
LOCAL_LLM_PROVIDER=lmstudio
```

`CHAT_PROVIDER` переопределяет общий провайдер, `CHAT_MODEL` — модель.
Если эти параметры не заданы, используются `LLM_PROVIDER` и `YANDEX_MODEL`.
Допустимы короткое имя модели и полный URI `gpt://<folder>/<model>`.
Модель должна поддерживать вызов инструментов.

`LOCAL_LLM_PROVIDER` отдельно управляет Documents/RAG/worker и локальными
эмбеддингами. Настройки внешнего Consultant и облачного RAG независимы.
`CODING_PROVIDER`, `CODING_MODEL`, `DATABASE_PROVIDER`, `DATABASE_MODEL`
сохранены для совместимости, но отдельные модели в приложении не запускают.
`CODING_ALLOWED_ROLES` сохраняет список разрешённых ролей инструмента GitHub.

После изменения настроек пересоздайте assistent с теми же Compose-файлами,
с которыми запускали систему. Для конфигурации с диагностикой:

```powershell
docker compose -f docker-compose.yml -f docker-compose.prod.yml -f docker-compose.diagnostics.yml up -d --build --no-deps assistent
```

Ключ и каталог обязательны; вызовы требуют прав на генерацию и доступной квоты.
Секреты задавайте в `.env`, не отправляйте их в чат и не коммитьте.

## Контекст и права

При выборе Yandex сообщения, доступная история и результаты инструментов
отправляются облачной модели. Это могут быть внутренние документы, код GitHub,
схемы и результаты SELECT. Ограничение внешнего Consultant публичными текстами
не распространяется на внутреннего агента.

Набор инструментов фильтруется перед каждым вызовом модели по текущей роли.
GitHub и PostgreSQL доступны только разрешённым ролям, только на чтение;
выполнение инструмента повторно проверяет пользователя. При смене области
доступа прежняя история не передаётся как текущий контекст. API-ключи
инструментов не добавляются в сообщения модели.

Параметры генерации: `CHAT_TEMPERATURE`, `CHAT_MAX_TOKENS`.
Таймаут отдельного обращения — `YANDEX_TIMEOUT_SECONDS`.
Автоматического перехода на локальную модель при ошибке Yandex нет.

Документация: https://aistudio.yandex.ru/ru/docs/ai-studio/quickstart/
