# Суммаризация диалога

Assistent использует готовую асинхронную функцию `asummarize_messages` из
`langmem.short_term` (LangMem 0.0.30). Новая зависимость и её транзитивные
зависимости зафиксированы в `Assistent/uv.lock`.

Адаптер `services/dialogue_summary.py` сохраняет правила VIIO: область доступа
пользователя, исключение ToolMessage и AIMessage с вызовами инструментов из
суммаризируемых сообщений, недоверенный статус сводки и целостность последних
ходов диалога. Старая сводка передаётся LangMem как RunningSummary. Формат
чекпоинта (`dialogue_summary`, `summary_upto`) не меняется; миграция не нужна.
Полная история остаётся в чекпоинте, сокращается только вход модели.

Настройки остаются прежними: `CONVERSATION_SUMMARY_ENABLED`,
`CONVERSATION_SUMMARY_AFTER` (порог в сообщениях),
`CONVERSATION_HISTORY_MAX_CHARS` (бюджет входа в символах).
Внутри LangMem используется приблизительный счётчик токенов без загрузки
токенизатора; бюджет суммаризируемого текста — 6000 токенов, сводки — 600.
Результат дополнительно ограничивается 2400 символами. Последние ходы сохраняются
отдельно; при переполнении длинной истории LangMem может обрезать старый текст.

Сводку создаёт выбранная модель соответствующего агента, включая Yandex,
если он выбран провайдером. Таймаут суммаризации — 20 секунд. При ошибке
сохраняется прежняя сводка и применяется ограниченное окно сообщений.
При смене области доступа прежняя сводка сбрасывается.
Запрет копировать код, секреты и результаты инструментов задан также в промпте;
это не автоматическое удаление секретов, уже написанных в обычном тексте беседы.

После обновления пересоберите Assistent:

```powershell
docker compose up -d --build assistent
```
