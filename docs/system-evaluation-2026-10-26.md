# Проверка VIIO — 26 октября 2026

Сервисы работоспособны, coder выдаёт код в чат без инструментов. Обнаружены две
ошибки маршрутизации, одна из них приводит к ответу без опоры на документы.
Изменения в рабочий код в рамках этой проверки не вносились.

## Проверенный состав

- Консультант: `qwen/qwen3-4b-2507`, поиск по действующей базе знаний.
- Coder: `qwen2.5-coder-1.5b-instruct`, текстовый режим без tools.
- APIAgent, WebChat, PostgreSQL и Qdrant работоспособны до и после проверки.
- 57 тестов APIAgent и 19 тестов WebChat прошли. Полная сборка WebChat, включая
  проверку типов, завершилась успешно.

## Проверка реальных ответов

Выполнено 15 запросов к работающим моделям, включая три через сервер WebChat
с настоящей временной сессией. Все получили HTTP 200; это само по себе не означает
правильность ответа. Ожидаемый маршрут подтверждён в 13 из 15 случаев по истории
общего агента и отдельным checkpoint coder. Это результат небольшого диагностического
набора, а не оценка качества на всех возможных запросах.

Четыре ответа с кодом дополнительно проверены на тестовых данных: три Python-ответа
и один SQL-ответ. Все проверки прошли. Для Python выполнялась только извлечённая
функция после ограничения допустимых узлов AST; пример использования из ответа
не запускался. SQL проверялся в SQLite в памяти; специфические возможности PostgreSQL
и производительность запросов не оценивались. Эти проверки выполнял тестовый стенд,
сама модель coder ничего не выполняла.

У coder во всех проверенных историях 0 tool calls и 0 ToolMessage.
Ответы coder в успешных случаях занимали 0,37–7,38 секунды. Вопросы по базе знаний
занимали 3,97–13,32 секунды. Замеры единичные, без нагрузочного тестирования.

## Найденные ошибки

### 1. Короткое продолжение теряет маршрут и контекст coder

Последовательность в одном диалоге:

1. `/code Напиши функцию multiply(a,b) на Python. Она возвращает произведение. Код в чат.`
2. `Добавь проверку отрицательных значений аргументов и возвращай None для них.`

Первый ответ содержит правильную функцию. Второй запрос попадает консультанту,
который ищет по документам и отвечает: «Недостаточно данных для ответа на вопрос».
История coder при этом не пополняется вторым запросом.

Причина: `MultiAgentService.chat` выбирает маршрут по тексту только текущего сообщения.
Короткое продолжение не совпадает с шаблонами; предыдущий выбор модели не учитывается.
При явном `/code` продолжение работает и предыдущая функция сохраняется в контексте.

Нужная доработка: учитывать предыдущую задачу и выбранного специалиста при коротких
продолжениях, сохраняя возможность переключиться к вопросам по документам.

### 2. Отрицание «код писать не нужно» ошибочно вызывает coder

Запрос:

`Как добавить новый отчёт в модуль SSRSReport? Опиши шаги по документам, код писать не нужно.`

Выбран coder, поиска по базе знаний нет. Он выдаёт общие шаги через SSRS Management
Studio без ссылки на документ. В реальном документе «Добавление нового отчета в
SSRSReport» описаны два разных конвейера, контроллеры `DefaultController` и
`FormController`, типы отчётов 1/2 и обязательная регистрация в `AvailableReports`.
Ответ этих требований не отражает. Его нельзя считать подтверждённой инструкцией
для данного проекта.

Причина: шаблон `CODING_INTENT` сопоставляет «добавить … код» и не учитывает отрицание
или явную просьбу ответить по документам.

Нужная доработка: различать просьбу написать код и вопрос о проекте по документации;
учитывать отрицания и приоритет явного запроса пользователя.

## Полный путь WebChat и очистка

Проверены регистрация временного пользователя, создание диалога, сохранение шести
сообщений, отказ сотруднику в доступе к coder и успешный вызов после назначения
тестовому пользователю роли администратора. Анонимный запрос к диалогам и запрос
к APIAgent без внутреннего токена возвращают 401.

После проверки временная учётная запись удалена вместе с её сессиями, диалогом
и сообщениями. Checkpoint тестовых запросов удалены отдельно. Контрольный запрос
подтвердил отсутствие пользователей `viio_eval_*`. Чужие записи не менялись.

Проверка охватывает HTTP-путь и сохранение истории. Визуальная проверка браузера,
длительные сессии, одновременная нагрузка и оценка сложных программ не проводились.
