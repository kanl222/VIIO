# Загрузка PDF

Администратор загружает PDF в разделе **«Администрирование» → «База знаний» → «Выбрать файл»**. После обработки текст появляется в форме: проверьте распознавание, задайте название и права доступа, затем нажмите **«Добавить в базу знаний»**. До этого нажатия документ не индексируется. Оригинальный PDF не сохраняется в файловом хранилище.

Поддерживаются текстовые PDF и сканы. По умолчанию разрешены файлы до **10 МБ**, **50 страниц**, **500 000 символов** извлечённого текста. TXT/Markdown по-прежнему ограничены 2 МБ. Зашифрованные и повреждённые PDF отклоняются. Если обработка не завершилась полностью, документ не добавляется автоматически.

## Запуск Docling на CPU

Текстовые PDF обрабатываются через pypdf без дополнительных сервисов. Для сканов запустите отдельный локальный сервис Docling из корня проекта; команды одинаковы для Windows PowerShell и Linux Bash:

```text
docker compose --profile pdf up -d --build pdf-worker assistent webchat
docker compose --profile pdf ps
docker compose logs --tail 30 pdf-worker
```

При первой сборке нужен интернет для установки зависимостей, при первом запуске — для загрузки публичных моделей Docling. Модели сохраняются в Docker-томе `docling_models`; последующие запуски используют этот кэш. Первая подготовка может занять несколько минут. Сервис готов после запуска Uvicorn и успешной проверки здоровья.

Обработка выполняется на CPU: установлена CPU-сборка PyTorch, GPU не требуется. Контейнер ограничен двумя ядрами и 4 ГБ памяти. OCR использует Tesseract с русским и английским языками. Документы обрабатываются локально; удалённые сервисы и внешние плагины Docling отключены. Возможности настроены по [официальной документации Docling](https://github.com/docling-project/docling/blob/main/docs/usage/advanced_options.md).

## Конфигурация

Параметры задаются в корневом `.env`:

```dotenv
PDF_ENGINE=auto
PDF_MAX_PAGES=50
PDF_MAX_CHARS=500000
PDF_TIMEOUT_SECONDS=120
DOCLING_URL=http://pdf-worker:8080
DOCLING_CPU_THREADS=2
```

| `PDF_ENGINE` | Поведение |
| --- | --- |
| `auto` | pypdf извлекает встроенный текст; если хотя бы на одной странице нет текста, весь PDF передаётся Docling |
| `docling` | Все PDF обрабатываются Docling, включая анализ структуры и таблиц |
| `pypdf` | Только встроенный текст; страницы без текста требуют включения Docling |

Режим `auto` не обнаруживает текст внутри изображения, если на той же странице уже есть встроенный текст. Для таких документов и сложных таблиц используйте `docling`. Проверяйте результат OCR: сокращения, числа и порядок чтения могут распознаваться неверно.

После изменения конфигурации повторите команду запуска. Обрабатывается один PDF одновременно; при занятом сервисе интерфейс предлагает повторить попытку. Тайм-аут прерывает отдельный процесс преобразования. Большой скан лучше разбить на части. Если Docling не запущен, текстовые PDF продолжают работать в режиме `auto`, а скан вызывает понятное сообщение об ошибке.

Загрузка доступна только администраторам; права индексированного текста задаются существующей формой. Coder не получает инструментов работы с файлами.

## Проверка 26.10.2026

Пройдены 116 тестов assistent и 32 теста WebChat, включая проверки ролей, бинарной передачи PDF, лимитов, повреждённых файлов, паролей и отсутствия индексации на этапе просмотра. Сборка WebChat успешна. На работающем CPU-сервисе распознан синтетический скан с русским и английским текстом: одна страница заняла около 48 секунд при первом преобразовании. Дополнительно проверена реальная цепочка assistent → Docling: текстовый PDF обработан за 0,27 с, отдельный скан — за 23,46 с. Это проверка работоспособности, а не оценка скорости для произвольных документов. OCR исказил сокращение VIIO, поэтому проверка текста перед сохранением обязательна.

Визуальная проверка в браузере не завершена: подключённые браузеры не смогли открыть локальный тестовый сервер (тайм-аут соединения). Серверные проверки формы и сборка пройдены. Архитектурный анализ не обнаружил циклов; число функций повышенной сложности выросло с 10 до 11 — это остаётся ограничением сопровождаемости.
