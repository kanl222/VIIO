# Контекст из базы знаний и роль программиста — 26 октября 2026

> Обновление 26.10.2026: по новому решению пользователя coder доступен ролям `programmer` и `admin`. Описанные ниже результаты относятся к прежнему ограничению. Актуальные правила: [настройка coder](coding-agent.md).

Реализован путь: задача → поиск с правами текущего пользователя → справочные факты
в текущем запросе coder → код в чат. Для простых автономных функций поиск пропускается.
Именованный документ ищется по названию; соседние документы не подменяют требуемый.
Если нужный документ не найден среди доступных результатов, VIIO запрашивает уточнение.

Модель coder остаётся `qwen2.5-coder-1.5b-instruct`, без tools, файлов и выполнения.
В постоянных сообщениях сохраняются исходная задача и ответ, но не добавленная справка.
В метаданных ответа сохраняются объём контекста и ID найденных документов.

Доступ к coder разрешён только роли `programmer` («Программист»). Администратор может
назначить её в разделе «Администрирование → Пользователи»; роль администратора
сама по себе не даёт доступа к coder. Существующие пользователи не переназначались.
Программист наследует доступ к документам сотрудников, но не руководителей и администраторов.

Проверки:

- 67 тестов APIAgent и 19 WebChat прошли; сборки обоих сервисов успешны.
- После последнего изменения оформления источников повторно прошли 31 профильная проверка.
- Через настоящий WebChat проверены отказ администратору и сотруднику, назначение
  программиста через Admin API, запрет программисту изменять роли, отзыв роли на следующем запросе.
- Самостоятельное указание роли программиста при регистрации игнорируется сервером.
- По документу «Добавление нового отчета в SSRSReport» найден `doc-cbcd7191`, coder
  получил 823 символа справки и вернул правильные значения типов отчётов: SSRS=1, ИСЛО=2.
  Словарь проверен через безопасный разбор литерала, без исполнения кода модели.
- Для простой `add(a,b)` справка не передавалась.
- У coder 0 tool calls / 0 ToolMessage. При отзыве роли новых вызовов модели не было.
- Временные пользователи, диалоги, сессии и checkpoint проверок удалены.

Во время проверки обнаружены и устранены поиск соседних документов по длинному запросу
и склонность небольшой модели копировать справку в код вместо использования её фактов.
Повторная проверка конкретного сценария прошла; это не гарантия качества всех программ.
Короткие продолжения без `/code` пока могут попасть консультанту — известное ограничение
маршрутизации из предыдущего отчёта сохраняется.
