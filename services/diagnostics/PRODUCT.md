# Разбор агентов VIIO

Пользователь попросил отдельный сайт на React, доступный только локально,
для диагностики основного агента и внешнего консультанта. Нужны одновременно
пошаговый разбор реальных запросов, сравнение с эталоном, сводка ошибок и скорости.

Основная задача: выяснить, почему агент дал неверный ответ, сопоставив кандидатов
поиска, отобранные фрагменты, фактический контекст модели и окончательный ответ.
Успех — пользователь может открыть конкретный запрос и обоснованно отметить
первый этап ошибки, сохранив эталон и наблюдения.

Сайт показывает только записанные события. Он не восстанавливает прошлые запросы
и не назначает автоматически смысловую оценку. Буквальное наличие фразы и
успешное выполнение HTTP-запроса не равнозначны правильному ответу.

Рабочий режим — Operate: быстро найти запрос, раскрыть нужный этап и сохранить
разбор. Оформление наследует существующую систему VIIO из корневого DESIGN.md:
нейтральные поверхности, индиго для действий, светлая и тёмная темы, Segoe UI,
Lucide, таблицы и списки без декоративных теней.

Сервис слушает на хосте 127.0.0.1:3010, не получает рабочие ключи и доступ к БД.
Трассы агентов изолированы; сайт читает их, а оценки сохраняет отдельно.
