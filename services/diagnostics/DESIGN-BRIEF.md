# Направление интерфейса

THESIS: Открытый запрос показывает, какие сведения прошли через каждый этап ответа.

OWN-WORLD: Наследуем существующее оформление VIIO из D:/Source/VIIO/DESIGN.md.
Новая визуальная идентичность не создаётся. Подтверждённый пользователем формат:
отдельный локальный React-сайт с журналом, эталоном и сводкой.

STORY: Выборка и сводка → выбор вопроса → цепочка событий → краткий ответ →
кандидаты рядом с отобранными фрагментами → эталон и ручной разбор → сравнение
с другим сохранённым ответом на тот же вопрос.

FIRST VIEWPORT: Заголовок задачи, сводка и фильтры, журнал слева и выбранный
запрос справа. Цепочка этапов предшествует длинному ответу, который свёрнут
по умолчанию. На мобильном экране журнал предшествует разбору.

FORM: Плоские нейтральные поверхности, системная типографика, существующие
семантические цвета VIIO, раскрываемые события с временем и текстовыми статусами.
Все данные реальные, отсутствие события обозначено явно. Свободный текст
выводится средствами React как текст. Цвет не служит единственным обозначением.
